# 📌 Project Overview

The Cyber Attack Detection System is a Machine Learning-based web application developed to identify and classify cyber attacks using network traffic data. The system analyzes multiple network parameters and predicts whether the traffic behavior is normal or malicious.

This project helps improve cybersecurity monitoring by detecting suspicious activities in real time using intelligent prediction models.

# ⚙️ Installation Guide

## Step 1: Clone Repository

```bash
git clone https://github.com/your-username/network-cyber-attack-detection.git
```

## Step 2: Move to Project Directory

```bash
cd network-cyber-attack-detection
```

## Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

## Step 4: Run Application

```bash
streamlit run app.py
```
